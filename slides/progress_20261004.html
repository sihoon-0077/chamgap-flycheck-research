결과 ② 실제 초파리 연결 (가설 H2)

실제 초파리 연결의 이점은 관찰되지 않았다

  • 판정 규칙은 결과를 보기 전에 사전 계획서로 고정했다.
  • 데이터 50·100개: 시드 30개로는 구간이 넓어 판정 불가.
  • 데이터 200개: 결과를 보지 않은 새 시드 80개로 다시 확인했더니, 실제 연결 = 재배선 = MLP (±0.10).
발표 문장

이 시뮬레이터에서는 실제 초파리 연결 위치의 이점이 ±0.10 안에서 관찰되지 않았다.

쓰지 않는 문장: "초파리 구조가 우수하다", "열등하다". 센서 입력을 PN으로 바꾸는 어댑터가 학습되므로, 연결 위치의 차이를 어댑터가 흡수했을 수 있다.
