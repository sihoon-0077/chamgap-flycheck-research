# 펌웨어 구현 계약 — 아직 구현되지 않음

보드 모델·센서 모듈·모터 드라이버를 수령해 검수한 뒤 작성한다.
이 폴더에 실제 실행용 `main.cpp`가 들어 있다는 뜻이 아니다.

필수 모듈: 센서 수집, telemetry, command, safety, storage.
부팅 직후 모터 OFF. 미완료 명령 자동 재실행 금지. 동일 request_id 중복 실행 금지.
펌프 명령 retained=false, 만료·물량·시간·구역 검사. GPIO 직결 구동 금지.
최초 검수 계획 한도: 10mL/회, 20mL/세션, 최대 2회, 연속60초 이내.
이는 작물별 안전 급수량이 아니라 검수 시작값이며 실제 승인 필요.
서버 불능·누수·정지·시간 초과·관련 계측 오류에서도 장치가 안전 상태로 전환되어야 한다.

라이브러리를 정하기 전에 I2C 주소·3.3V 로직·ADC 범위·핀 사용을 확인한다.
상세 핀·물길·조립·하드웨어 검수 절차는 마스터 문서 20~21장에 있다.
