# 사전 계획서 — connectome_v1 학습곡선

작성: 2026-10-04. 실제 연결 행렬로 학습한 모델의 결과를 하나도 보기 전에 작성했다. 이 파일의 SHA-256은 본 실험 manifest에 기록한다. 이 파일을 실험 뒤에 고치면 해시가 달라지므로, 고친 사실이 드러난다.

라벨: domain=SIM_ONLY_UNCALIBRATED. 결과는 보정하지 않은 시뮬레이터 안에서만 성립한다.

## 1. 질문

설계서 5.3절 H2. 같은 학습 예산에서, 실제 PN→KC 연결(P3)이 차수 보존 재배선(P2)과 크기 맞춘 MLP(P1)보다 **적은 데이터에서** 높은 성능을 내는가?

## 3. 주 지표와 주 비교

- **주 지표:** 시험 사건당 평균 보상 (보상 v2).
- **주 비교 6개:** P3 − P2, P3 − P1, 각각 n = 50, 100, 200.
- 같은 데이터 시드끼리 짝지은 차이를 계산한다. 시드 단위로 bootstrap을 10,000번 해서 평균 차이의 신뢰구간을 구한다 (난수 seed 20261004). 비교가 6개라 Bonferroni 보정으로 **99.17% 구간**(양쪽 0.417%)을 쓴다.

## 4. 판정 규칙

비교마다 하나로 판정한다.

| 판정 | 조건 |
|---|---|
| P3 높음 | 구간 전체가 0보다 큼 |
| P3 낮음 | 구간 전체가 0보다 작음 |
| 동등 (±0.10) | 구간 전체가 −0.10 ~ +0.10 안 |
| 판정 불가 | 위 어느 것도 아님 |

"P3 높음"과 "동등"이 동시에 성립하면(구간이 0보다 크면서 +0.10 안), "P3 높음, 차이는 0.10 미만"으로 함께 적는다. ±0.10은 P0 보상(2.25)의 약 4%다.

**결과별 발표 문장** (설계서 5.5절)
- 주 비교 중 P3 − P2가 n ≤ 200 어디서든 "P3 높음": "이 시뮬레이터에서, 데이터가 N개일 때 실제 연결이 같은 차수의 재배선보다 보상이 높았다."
- P3 − P2가 n ≤ 200 세 곳 모두 "동등": "이 시뮬레이터에서는 실제 연결 위치의 이점이 ±0.10 안에서 관찰되지 않았다."
- 그 밖의 경우: 판정별로 그대로 보고한다.

어느 경우에도 "초파리 구조가 우수하다", "진화한 구조라서 낫다"는 쓰지 않는다 (설계서 5.6, 12.7절).

## 7. 변경 기록

### 변경 1 (2026-10-04) — n=200 시드 확대. 주 결과를 본 뒤의 결정

이 절은 1–6절을 바꾸지 않는다. 1–6절의 해시는 본 실험 manifest의 값과 같아야 한다 (이 절 앞까지의 바이트로 확인).

- **이유:** 주 비교 6개가 모두 "판정 불가"였다. 2절에 적은 정밀도 추정(구간 반폭 0.03–0.09)이 틀렸다. 실제 반폭은 0.07–0.14였다. 원인은 두 가지다. (1) 추정은 95% 기준(z=1.96)으로 했는데 판정은 99.17% 기준(z≈2.64)이었다. (2) n=50·100에서 짝지은 차이의 시드 간 SD가 0.24–0.29로 추정 범위의 상한이었다. 사용자가 n=200 확대(B안)를 골랐다.
- **원래 주 결과는 그대로 둔다.** 6개 모두 "판정 불가"이고, 이 변경은 그 결과를 대체하지 않는다.
- **추가 데이터:** n=200만, 새 데이터 시드 80개 = 3,000,000 + 250,000·k (k = 0…79). 시드마다 collect()의 rollout 시드 범위(seed + 1009g + 101d + r)가 서로 겹치지 않고, 기존 묶음의 범위(최대 2,017,491)와도 겹치지 않는다. 기존 시드 규칙(나머지 격자)으로는 63개까지만 고를 수 있어서 방식을 바꿨다. 모델 4종, 튜닝으로 고른 학습률(P1 0.001, P2 0.003, P3 0.001, R 0.01), 그 밖의 조건은 2절과 같다.
- **확인 분석 (이 변경의 주 분석):** 새 시드 80개만 쓴다. 이미 결과를 본 시드 30개와 섞으면 "차이가 날 때까지 더 모으는" 효과(optional stopping)로 우연한 차이를 발견으로 착각할 확률이 커지기 때문이다.
  - 비교 2개: P3 − P2, P3 − P1 (n=200, 사건당 평균 보상).
  - 같은 시드끼리 짝지은 차이, 시드 단위 bootstrap 10,000회 (난수 seed 20261004), Bonferroni 2개 → **97.5% 구간**.
  - 판정 규칙은 4절과 같다 (±0.10 동등 범위 포함).
  - 예상 정밀도 (이번에는 판정과 같은 기준으로 계산): 기존 30개 시드의 SD(0.143, 0.199)를 쓰면 97.5% 구간 반폭 ≈ 2.24 × SD / √80 = 0.036, 0.050.
- **기술 분석 (판정에 쓰지 않음):** 기존 30개 + 새 80개 = 110개를 합친 차이와 99.17%·95% 구간. 보조 지표(4절 5항)의 n=200 값도 110개 기준으로 함께 보고한다.
- **발표 문장:** 확인 분석 기준으로 4절의 문장 규칙을 n=200 하나에 적용한다. P3 − P2가 "P3 높음"이면 "이 시뮬레이터에서, 데이터 200개일 때 실제 연결이 같은 차수의 재배선보다 보상이 높았다(독립 시드 80개로 확인)."; "동등"이면 "…±0.10 안에서 차이가 관찰되지 않았다."; 그 밖에는 판정별로 그대로 보고한다.
